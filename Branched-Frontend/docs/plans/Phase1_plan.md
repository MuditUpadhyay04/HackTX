# Phase 1 plan: the white iPhone Duo + the fold control

**Planner:** Opus (Fable out of credits). **Spec:** `docs/CLAUDE_PROMPT.md` Phase 1 block (geometry, materials, states, fold control, acceptance 1–17). Gurneal approved building all phases without stopping.

## Goal
`<IPhoneDuo>` as a pure function of `openAngle` (0 folded … 180 flat) with every static state, the `/device` page with test patterns and a `?debug=1` spec overlay, the glass **Fold/Unfold** control + `F` key driving `openAngle` with `springUnfold` (interruptible, detent ripple, reduced-motion crossfade), `useFold()` + `window.__unsaidDevice`, and `UnsaidLogo`.

## Interfaces
- `import { IPhoneDuo } from "@/components/device/IPhoneDuo"`; `import { GEOM, displayRect } from "@/components/device/geometry"`; `import { deviceTransform, STATE_ANGLES } from "@/lib/device/angle"`; `import { useFold, useDeviceAngle } from "@/lib/device/fold"`.
