# Un-Said wordmark and app name

- **Displayed name: "Un-Said"** (capital U, hyphen, capital S). Confirmed by Gurneal, Oct 24, 2026.
- Use "Un-Said" on every user-facing surface: the home-screen icon label, the notification banner app name, the launch splash, the slides, and on-screen text in the demo.
- Code identifiers, routes, folders and file names stay `unsaid` (e.g. `components/unsaid/`, `/brand/unsaid-app-icon.png`). Specs may write "Un-Said (Unsaid)" on first mention.
- Wordmark style: from App-UI-Final's synced theme (`lib/unsaid-theme.json`, `un-wordmark`); live text, no image file. Never type the values by hand here.
- The mark is the white rounded opening quote “ from `unsaid-app-icon.png`. Older marks are retired.
- iOS truncates labels near 11 characters; "Un-Said" (7) fits.
