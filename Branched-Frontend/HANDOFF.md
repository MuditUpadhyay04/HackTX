Written Oct 25, 2026. Read this first, then `APPS_PROGRESS.md` (app details) and `BUILD_LOG.md` (history).

## What this is

A web mock of the **iPhone Duo** (Apple's foldable, launched Oct 23, 2026) for the HackTX Un-Said demo. It's a CSS-3D phone that folds and unfolds, with an iOS home screen and working look-alike apps. The **real Un-Said app** runs inside it.

- **Phone:** Next.js app in `Branched-Frontend/`, repo `MuditUpadhyay04/HackTX`.
- **Un-Said:** Gurneal's Expo app (`mobile/`) and Mudit's FastAPI backend (`backend/`), in the same repo.

## Run the demo

```bash
cd ~/HackTX/Branched-Frontend
npm run demo
```

This:
1. starts Un-Said's backend on :8000, with mock AI unless `backend/.env` has `MODEL_API_KEY`;
2. builds Un-Said into the phone if needed;
3. fills the demo data (`scripts/fill-unsaid-demo.py`);
4. runs the phone at **http://localhost:3000/device**.

**Flags:**
- `--rebuild`: pull `demo-fill` and rebuild Un-Said.
- `--no-fill`: keep the backend data as it is.

**Controls:** the Fold / Unfold pill, the **F** key, or the 0–180° slider under the phone (it snaps to each degree).

## What was built (all in `Branched-Frontend/`)

**Device** (`components/device/`, `lib/device/`):
- **Hinge:** a 1.4 s smoothstep tween with no overshoot (`hingeTween` in `lib/motion.ts`).
- **Blur:** the swinging half blurs as a gradient from the crease, and the still half stays sharp.
- **Seams:** a 2 px hinge overlap means no seam line at any angle. One seamless front panel shows when flat.
- **Buttons:** placed as shipped (volume on top; Touch ID and Camera Control on the right), clickable.
- **Cover layer:** a flat, clickable copy of the outer screen sits on top while folded. The app's built-in browser can't click through the flipped face.

**Home screen** (`components/home/`):
- clean drawn Phone, Messages and Photos icons;
- a darker wallpaper, the Music and Reminders widgets, and an iOS 26 frosted dock;
- Duo-style status: time, Wi-Fi and battery stacked top-right.

**App system:**
- `lib/apps/registry.tsx` is the one table linking every button to an app on both screens. `null` means the button does nothing.
- `lib/apps/store.ts` holds the open app and its navigation stack, shared by both screens, so folding keeps your place.
- `components/home/AppHost.tsx` runs the iOS launch zoom: a clip grows from the icon, nothing is scaled, so it stays sharp. Only the copy you can see runs the app, except for apps in `KEEP_MOUNTED`.
- `lib/apps/copies.ts` marks the hidden copies of each screen used on the folding halves.

**Look-alike apps** (`components/apps/`):
- **Shared kit** (`kit.tsx`): iOS push/pop, a split view for the open screen, and shared buttons and rows.
- **WhatsApp:** chats, Mom's thread, Calls, the call screen, and every tab.
- **Messages:** Sarah's chat, with Delivered/Read and typing dots.
- **Instagram:** the DMs inbox, Michael's chat with reel cards, and a Reels viewer.
- **Photos:** a library grid and a photo viewer.
- Fake data lives in `lib/mock/*` and message state in `lib/store/messaging.ts`.

**Un-Said inside the phone** (`components/apps/unsaid/UnsaidApp.tsx`):
- `scripts/build-unsaid.sh` exports the Expo web build into `public/unsaid/` (git-ignored). `next.config.ts` rewrites `/unsaid/*` to it.
- It runs same-origin in the screen, with no scrollbars or focus rings.
- A splash rides the launch zoom.
- The route is shared, so a fold keeps the Un-Said screen you're on.

**Un-Said changes** (branch `demo-fill` only):
- **App icons:** the real app icons replace the generic glyphs (`AppRail`).
- **Library on the web build:** it reads the server's photos.
- **Notes to yourself:** it frames Riley before recording.
- **Talk:** wide and short layouts fixed.
- **Narrow pages:** centered on web.

## User preferences (important)

- **Don't ask "is it fixed / commit?" after every change** while the user is iterating. Just do it and say briefly what changed.
- **Never claim a visual fix is done without checking it.** For the fold, that means every angle (contact sheets at 1–180°).
- **Reset any test zoom** in the browser pane before handing back.
- **Saving:** "save it" means commit and push the phone to `iphone-duo-template` and move `app-demo-v1` to the same commit. Un-Said changes go only to `demo-fill`, never `main`.
- **Demo, not production:** no placeholders or empty states anywhere.
