# Un-Said wordmark and app name

- **Displayed name: "Un-Said"** (capital U, hyphen, capital S). Confirmed by Gurneal, Oct 24, 2026.
- Use "Un-Said" on every user-facing surface: the page title, the home-screen label, the PWA manifest, notifications, the launch splash, the in-app header, link previews and the slides.
- Code identifiers, routes, folders and file names stay `unsaid` (e.g. `unsaid-app-icon.png`). Specs may write "Un-Said (Unsaid)" on first mention.
- Wordmark style (from the reference Home screen): `un-wordmark` 24/28 pt, weight 800, tracking -0.01em, `un-text` #FFFFFF on `un-bg` #0F0D15, leading-aligned at the 24 pt text inset. Live text in the `un-sans` stack (no image file), so it stays crisp; no logo lockup with the icon inside the app.
- The mark is the white rounded opening quote “ from `unsaid-app-icon.png`. Older marks are retired.
- iOS truncates labels near 11 characters; "Un-Said" (7) fits.
